# Metadata Engineering

## Иерархия источников истины
1. разрешённая тестовая ИБ;
2. актуальный дамп конфигурации;
3. canonical XML проекта;
4. BSL Language Server;
5. текстовое предположение.

Не выдумывать имена метаданных, реквизитов, форм и команд, если их можно получить исследованием.

## Probe
- определить точный объект и родителя;
- перечислить реквизиты/табличные части;
- определить формы и команды;
- найти модули и ссылки;
- зафиксировать точные имена и типы;
- только после этого писать код/XML.

## Безопасность
Изменять только необходимое. Не переименовывать существующие объекты ради стиля. Не менять архитектуру во время реализации.
