# Установка в Default Project

Скопировать содержимое этого каталога в:

`C:\Users\Home\Documents\Default Project\.opencode\skills\`

Важно:
1. Не удалять существующие skills.
2. После копирования перезапустить OpenCode.
3. Проверить `opencode debug agent` для пяти агентов.
4. Затем повторить Golden Path.
5. Если Golden Path PASS — только после этого подключать read-only metadata MCP.

Права developer остаются `edit: allow` только для `src/**`.
