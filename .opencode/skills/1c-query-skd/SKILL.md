# Query / SKD

## Query
Перед написанием определить реальные имена метаданных и полей. Проверить:
- joins и cardinality;
- параметры и типы;
- поля результата;
- фильтры;
- grouping;
- nullability;
- performance-sensitive predicates.

Парсящийся запрос не обязательно корректен.

## SKD
DataCompositionSchema — структурированная metadata, а не свободный текст. Сохранять не относящиеся к задаче узлы и валидировать результат доступными средствами.

## Runtime
Если доступна разрешённая тестовая ИБ, проверять запрос на репрезентативных данных.
