## DISCOVERY REPORT
1. Тип документа: Справочник.ДокументыПредприятия.
2. Объект хранения файлов: Справочник.Файлы (реквизит ПодписанЭП, ТекущаяВерсия) + Справочник.ВерсииФайлов; бинарные данные — РегистрСведений.ДвоичныеДанныеФайлов.
3. Механизм присоединённых файлов: ОпределяемыйТип.ПрисоединенныйФайл (CatalogRef.Файлы + CatalogRef.ВерсииФайлов); модули ПрисоединенныеФайлы, РаботаСФайлами*.
   Подписи: РегистрСведений.ЭлектронныеПодписи (ПодписанныйОбъект, ПорядковыйНомер, Подпись, Отпечаток, УстановившийПодпись, Версия, ПодписьВерна).
4. Форма задачи подписания: БизнесПроцесс.Подписание (точки Подписать/ОбеспечитьПодписание/ОбработатьРезультат/ПовторитьПодписание);
   тип задачи Tasks.ЗадачаИсполнителя; рабочая карточка — Документ.ДействиеЗадачи.Форма.ФормаЭлемента.
5. Команда штатного подписания: динамическая команда результата «Подписано» -> РаботаСЗадачамиКлиент.ВыполнитьДействиеЗадачи.
6. Клиентский обработчик: РаботаСЗадачамиКлиент.ВыполнитьДействиеЗадачи -> ИнтеграцияЗадачКлиент.ОбработатьДанныеВыполнения (стр.17)
   -> ОбработатьДанныеВыполненияПодписатьПредметыЭП (стр.1544) -> РаботаСЭПКлиент.Подписать (стр.1614).
7. Серверный метод: РаботаСЗадачамиВызовСервера.ВыполнитьДействиеЗадачи -> ИнтеграцияЗадач.ПередИнтерактивнымВыполнениемДействияПодписаниеПодписать
   -> ИнтеграцияЗадач.ПредметыДляПодписанияЭП -> МультипредметностьКлиентСервер.ПолучитьМассивПредметовОбъекта.
8. Общий модуль ЭП: РаботаСЭП (сервер; ПолучитьОбъектыДляПодписи, ЗанестиИнформациюОПодписи(ях)); РаботаСЭПКлиент.Подписать(Данные, ПараметрыПодписания);
   БСП: ЭлектроннаяПодпись*, СервисКриптографии, ХранилищеСертификатов.
9. Формат параметров: РаботаСЭПКлиент.Подписать принимает ссылку на файл, структуру или Массив структур {ОбъектПодписания, ПараметрыДанных, ДополнительныеСвойства}.
10. Возможность подписания отдельного файла: YES (РаботаСЭПКлиент.Подписать принимает одиночную ссылку/массив; РаботаСФайламиКлиент.ПодписатьФайл — тоже массив).
11. Предлагаемая точка расширения: ИнтеграцияЗадачКлиент.ОбработатьДанныеВыполнения (Экспорт, клиент) — диспетчер; флаги в
    КонтекстВыполненияЗадачи.ДанныеВыполнения.ДополнительныеПараметры: ПодписатьПредметыЭП (Булево), НаборыПредметовДляПодписания (Соответствие ДействиеЗадачи->Массив предметов).
12. Требуется: расширение общего модуля (&Вместо) + собственная ОбщаяФорма выбора файлов. Перехват штатной команды не требуется.
