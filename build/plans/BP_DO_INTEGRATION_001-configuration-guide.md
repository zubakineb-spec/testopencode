# BP_DO_INTEGRATION_001 — Конфигурационная инструкция (Stage 1, без кода)

## Объём (подтверждён)
- Механизм: штатная «Интеграция с 1С:Документооборотом» (web-service SOAP http://www.1c.ru/dm).
- Только Stage 1 (конфигурация данных). Расширение (Stage 2) НЕ требуется (вне стандартных 9 ничего не нужно).
- Доп. соглашения: ДО-вид «Доп. соглашение» (ЯвляетсяДоговором) + в БП отдельный элемент ДоговорыКонтрагентов.
- Платежное поручение: только обратный поток ДО→БП (штатный, флаг ВыгружатьЗаявкиНаОплату).

## JKX (БП/ЖКХ) — источник
1. Включить ФО: кт_ИспользоватьИнтеграциюС1СДокументооборот.
2. Константы:
   - АдресВебСервиса1СДокументооборот = http://HOME/<ДО>/ws/DMService (или ws/dm.1cws)
   - ИнтеграцияС1СДокументооборотИмяПользователяДляОбмена / ПарольДляОбмена (пароль НЕ хранить в репо — сеансовые параметры/DPAPI)
3. Узел плана ExchangePlan.ИнтеграцияС1СДокументооборотом + Состав (НСИ: Организации, Контрагенты, ФизическиеЛица, Пользователи, ПодразделенияОрганизаций, БанковскиеСчета, КлассификаторБанков, Валюты).
4. Правила интеграции: Catalog.ПравилаИнтеграцииС1СДокументооборотом — 9 предопределённых (проверить наличие).
5. Рег. задание: ИнтеграцияС1СДокументооборотВыполнитьОбменДанными + роль ИспользованиеИнтеграцииС1СДокументооборотом.

## DocMng30 (ДО) — приёмник
1. Опубликовать web-service DMService (проверить публикацию/версию DMGetVersionRequest).
2. Узел плана ExchangePlan.ОбменБухгалтерияПредприятияДокументооборот20:
   - флаги ВыгружатьДоговоры=Истина, ВыгружатьЗаявкиНаОплату=Истина (для обратного ПП), ОграничиватьВыгрузкуОрганизациями=Истина, ГруппаДоступаКонтрагентов.
   - ТЧ Организации = ООО «Нижневартовскгаз».
   - ТЧ Договоры (ВидДокумента = «Договор с поставщиком/покупателем»), ТЧ ЗаявкиНаОплату (ВидДокумента = «Заявка на оплату»).
3. Виды документов ДО: «Договор с поставщиком», «Договор с покупателем» (ЯвляетсяДоговором), «Доп. соглашение» (ЯвляетсяДоговором), «Заявка на оплату» (ЯвляетсяЗаявкойНаОплату).

## Idempotency
- Регистр ОбъектыИнтегрированныеС1СДокументооборотом (Объект / ТипОбъектаДокументооборота / ИдентификаторОбъектаДокументооборота) — связь 1:1, повтор = update, без дублей.
- Регистр СоответствияОбъектовИнформационныхБаз (НСИ).

## Ограничение текущей среды
- COM-коннектор (V83.COMConnector) НЕ зарегистрирован (нет прав администратора) — прямой read-only probe live-ИБ невозможен.
- Для проверки фактического состояния live-ИБ нужен либо: регистрация comcntr.dll, либо probe-EPF через 1cv8.exe ENTERPRISE /Execute.
